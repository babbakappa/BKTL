# **BTKL - приложение список дел на Android**

## О приложении

* Данное приложение может помочь студентам записывать свои дела из университета или колледжа, чтобы не забывать о них
* Интерфейс приложения очень понятен и в нем легко разобраться

## Функционал

* Создание
* Удаление
* Редактирование
* Восстановление из удаленных (архив)
* Экспорт импорт из Excel файла
* Уведомление за день до дедлайна
* Задание своего списка предметов
* Управление своим списком предметов
* Цветовая тема на основе Material You

## На чем написано

* Язык Kotlin
* Jetpack Compose
* Room SQLite
* Apache POI (для экспорта/импорта xlsx файлов)
