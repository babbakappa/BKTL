# **BTKL - приложение список дел на Android**

## О приложении

* Данное приложение может помочь студентам записывать свои дела из университета или колледжа, чтобы не забывать о них
* Интерфейс приложения очень понятен и в нем легко разобраться

## Функционал

* Создание
* Удаление
* Редактирование
* Восстановление из удаленных (архив)
* Экспорт в Excel файл
* Уведомление за день до дедлайна

## На чем написано

* Язык Kotlin
* Jetpack Compose
* Room SQLite
* Apache POI
