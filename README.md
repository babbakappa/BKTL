# BTKL - приложение список дел на Android

## О приложении

* Данное приложение может помочь студентам, школьникам и не только записывать свои дела из университета, колледжа, школы, места работы и т.д., чтобы не забывать о них
* Интерфейс приложения очень понятен и в нем легко разобраться

## Функционал

* Создание
* Удаление
* Редактирование
* Восстановление из удаленных (архив)
* Экспорт импорт из CSV файла (Excel таблица)
* Уведомление за день до дедлайна
* Задание своего списка предметов
* Управление своим списком предметов
* Цветовая тема на основе Material You
* Сортировка задач
* Поиск задач

## На чем написано

* Язык Kotlin
* Jetpack Compose
* Room SQLite
